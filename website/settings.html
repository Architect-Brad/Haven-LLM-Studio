Haven Settings

Configure your Haven LLM Studio instance. Changes are saved to your browser and can be exported as environment variables.

Server Configuration

Server Port
The port Haven will listen on. Default is 1234.
Server Host
The host to bind to. Use 0.0.0.0 for network access.
Models Directory
Where GGUF models are stored.
Log Level
Verbosity of server logs.

Inference Settings

Temperature
Controls randomness. Lower = more deterministic.
0.8
Top K
Number of top tokens to consider during sampling.
40
Top P
Nucleus sampling threshold.
0.9
Max Tokens
Maximum tokens to generate per response.
256
Repeat Penalty
Penalty for repeating tokens.
1.1
Context Size
Maximum context window in tokens.

GPU & Hardware

GPU Layers
Number of model layers to offload to GPU. -1 = all layers.
CPU Threads
Number of CPU threads for inference. -1 = auto-detect.
Multi-GPU
Enable tensor splitting across multiple GPUs.
Cluster Mode
Enable master/worker cluster for distributed inference.
Changes are saved automatically to your browser.
